# 项目文档

[使用说明](../README.zh.md) · [开发约定](../AGENTS.local.md)

DSH 0.2.2-rc.5 没有独立的列表标题插槽。
插件通过 `sidebar.footer.action` 获取侧栏作用域，再把自己的标题控件挂到原生工具栏开头。
标题复用宿主当前语言下的列表名称，按钮、提示和实心箭头来自 Web shell 提供的原生组件库。
键盘先到达标题，再到搜索和右侧操作。原生标题仅在替代控件就绪后隐藏。
搜索、视图菜单、添加工作区和列表始终留在原生 React 树里。
挂载和列表筛选依赖 `data-sidebar-scrollport`、`data-sidebar-workspace-header` 和 `data-sidebar-list-area` 标记。
标题结构不匹配、侧栏收起或停用插件时，不接管标题，也不隐藏原生列表。
「需关注」从 `useSessions`、`useSessionStatus` 和 `useWorkspaces` 读取会话目录、
实时状态及工作区归属，并用子代理目录识别仍有子代理运行的父会话。
当前会话沿用原生选中条件：会话占用主视图，且没有全局面板处于激活状态。
它与其他保留会话走同一套行筛选和工作区归属规则。
[会话草稿插件](../../dsh-session-draft/docs/README.md) 启用时，可选 Client 服务会加入有草稿的会话 ID。
CSS 根据原生 `data-row-key` 筛选会话行和工作区标题。
工作区树折叠时若子工作区标题尚未渲染，插件使用已注册的目录祖先保留可见父级。
工作区展开、显示更多、菜单和导航仍由原生列表处理。
工作区和工作区树视图在各组自身会话之后放置独立的空闲会话开关，沿用原生组内「显示更多」的主题色和缩进。
父组、子组和「未分组」分别记录已显示的会话。
有需关注会话的工作区，或本次进入「需关注」后曾成功显示过空闲会话且仍有空闲会话的工作区，保留标题。
收起空闲会话时保留本次展开记录。「未分组」有空闲会话时保持可见。
平铺会话视图的开关位于原生滚动列表末尾，单独记录分页状态。
每次按当前组或平铺列表的原生顺序显示最多 5 条。
遇到原生组内分页边界时，调用该组的原生「显示更多」，等行更新后补齐本批。
已加载的行可以先显示。翻页期间，按钮保留键盘焦点并提示正在加载。
折叠的工作区由用户打开。搜索期间取消待续分页、暂停过滤并隐藏开关。
插件只读原生视图偏好 `dsh.workspace.view.v5`。「全部」按该归档筛选统计会话目录。
「需关注」的标题统计筛选命中的会话，同一会话只算一次，不受分组折叠或空闲会话分页影响。
「收起」排除只因置顶或当前选中而保留的会话，无活动或草稿时不显示数字。
标题数字以会话目录为准，不随独立的常驻区搬动行而改变。
目录尚未加载时不显示数字。「仅显示归档」时，展开态显示归档数。
「需关注」不筛选归档行，也不替换归档的空状态与操作。
空闲按钮统计当前组实际挂载的行。需要跨原生分页时，展开数字以「最多」表示。
升级后检查标题对齐、三态切换、折叠组标题、组内「显示更多」、搜索恢复，以及 Tab、Enter 和 Space。
停用插件应立即移除按钮和样式。

新检出后在项目根运行 `npm ci`，安装依赖并构建插件。
改动源码后用 `npm run build` 更新产物，再运行 `npm run check`，并从工作区根运行插件骨架检查。
